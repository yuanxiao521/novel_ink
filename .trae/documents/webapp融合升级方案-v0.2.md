# webapp 融合升级方案 v0.2

## Summary

以 `webapp/` 版本为底座（代码结构优、人物立绘、交互完整），融合我们版本的 3 个核心设计增量，使信息颗粒度对齐、作者工作流闭环。

升级后：作者工作台 = 左栏（角色卡 + 情绪条 + 信念账本）+ 中央（世界黑板 / 成文视图 双 tab）+ 右栏（导演控制台）+ 底部时间线（事件类型色点 + 图例）。

---

## Current State Analysis

### webapp 版本现状（优势底座）

- **代码结构**：HTML/CSS/JS 三层分离，tokens.css 语义变量体系清晰，BEM 风格命名
- **人物呈现**：三张 PNG 立绘（陈默/李文/周婶），40×40 圆形/方形头像
- **交互能力**：视图切换（工作台/阅读台）、深浅主题切换、mood 切换（悬疑/紧张/温情/宁静），均有真实 JS
- **布局架构**：三栏导播台 + 底部时间线，整体视觉完成度高
- **响应式**：1280 / 1024 / 768 三级断点

### 缺失的字段与模块（待融合）

| 模块 | webapp 现状 | 我们版本有的 | 差距 |
|------|------------|-------------|------|
| 角色卡 | 头像+名字+心情+目标+权重+信念总数 | 情绪条（平静→爆发进度）、信念账本分类标签（亲见/推测/被告知） | 缺少情绪可视化、信念颗粒度 |
| 中央舞台 | 仅"世界黑板"单视图 | 世界黑板 + 成文视图双 tab | 缺少成文预览，作者工作流不闭环 |
| 时间线 | 纯文字节点 + 红点当前态 | 事件类型色点（对话/行动/冲突/信息）+ 底部图例 | 缺少事件类型视觉区分 |
| 读者页 | 有沉浸阅读，对话带头像 | 聚光效果、顶栏底栏自动隐藏 | 视觉氛围可增强 |

## Proposed Changes

### 变更 1：角色卡升级 — 加情绪条 + 信念账本

**文件**：`webapp/index.html`、`webapp/css/app.css`

**改什么**：
- 在 `.char-card` 内，`char-goal-row` 下方新增 **情绪条区域**（`.char-emotion`）
  - 标签行：左侧"情绪"文字 + 右侧百分比数字
  - 进度条：`.emotion-track` + `.emotion-fill`，渐变从绿（平静）→ 金（紧张）→ 红（爆发）
  - 底部标签：两端"平静" / "爆发"小字
- 情绪条下方新增 **信念账本区域**（`.char-belief-list`）
  - 标题行："信念" + 数字（如"12 条 · 3 条待确认"）
  - 信念条目：每行一个信念，左侧带分类标签
  - 分类标签 4 种：`tag-witness`（亲见·绿色）、`tag-infer`（推测·金色）、`tag-told`（被告知·蓝色）、`tag-doubt`（存疑·红色）
  - 默认展示 3 条核心信念，"展开查看全部"用省略号暗示（v0.2 不做展开交互）

**为什么**：
- 情绪条是"导播台"隐喻的核心数据可视化，让作者一眼看到角色情绪水位
- 信念分类标签让作者快速理解每个角色的信息差，是涌现式小说的核心机制

**设计细节**：
- 情绪条高度 4px，圆角 2px，fill 用 `linear-gradient(90deg, var(--accent-green), var(--accent-gold), var(--accent-red))`
- 陈默 75%、李文 65%、周婶 25%（与我们版本一致）
- 信念标签 16px 宽，文字 9px，圆角 3px，背景用对应 accent 色的 15% 透明度
- 卡片整体高度从约 100px 增至约 180px，左栏仍可容纳 3 张卡（232px 宽）

### 变更 2：中央舞台加"成文视图" tab

**文件**：`webapp/index.html`、`webapp/css/app.css`、`webapp/js/app.js`

**改什么**：
- 顶部 `.tab-switch` 从两个按钮（世界黑板 / 成文）改为真实可切换的 tab
- 新增 **成文视图面板**（`.prose-view`），与 `.blackboard` 平级，默认隐藏
- 成文视图结构：
  - 章节标题（居中，大号衬线字体，"第七章 雨夜的试探"）
  - 叙述段落（`.prose-paragraph`，首行缩进 2em，行高 2）
  - 对话块（`.prose-dialogue`）：左侧角色小头像（22px 圆形立绘）+ 右侧对话文字（斜体，高亮色）+ 说话人名字标签（10px，金色）
  - 底部章节导航：上一章 / 第 7 章 / 下一章
- JS 里加 tab 切换逻辑：点击"世界黑板"显示 blackboard、点击"成文"显示 prose-view

**为什么**：
- 作者的核心工作流是"看黑板判断局势 → 看成文确认产出质量"，缺一不可
- 与读者页形成呼应：工作台的"成文"是草稿态，读者页的"沉浸阅读"是成品态

**设计细节**：
- 正文区衬线字体 `var(--font-reader)`，15px，行高 32px
- 对话块左边框 3px `var(--mood-primary)`，左侧内边距 14px
- 角色头像 22px 圆形，用现有的 `portrait-*.png`，`object-fit: cover`
- tab 切换用 class `.active` 控制 display，与现有视图切换模式一致

### 变更 3：时间线加事件类型色点 + 图例

**文件**：`webapp/index.html`、`webapp/css/app.css`

**改什么**：
- 每个 `.turn-node` 的 `.turn-dot` 增加事件类型 modifier class：
  - `.type-dialogue`（对话·青色）
  - `.type-action`（行动·蓝色）
  - `.type-conflict`（冲突·红色）
  - `.type-info`（信息·金色）
- 当前回合（T-07）保持红色高亮 + 呼吸动画，不受类型色影响
- 时间线右上角加 **图例**（`.tl-legend`）：四个小色点 + 文字标签，横向排列

**为什么**：
- 一眼扫过时间线就能判断剧情节奏（对话多还是行动多，冲突密度如何）
- 与"导演控制台"的监控隐喻一致，类似剪辑软件的时间轴

**设计细节**：
- 色点直径 8px（当前回合 10px 不变），过去节点 6px
- 颜色直接用已有的 accent 变量：cyan / blue / red / gold
- 图例放在 `.tl-meta` 左侧，字体 10px，颜色 `var(--text-muted)`
- 7 个回合的事件类型分配：T-01 行动、T-02 对话、T-03 信息、T-04 冲突、T-05 对话、T-06 行动、T-07 对话（当前）

### 变更 4（可选小优化）：读者页氛围增强

**文件**：`webapp/css/app.css`

**改什么**：
- 读者页背景加聚光效果（radial-gradient 从中心亮到四周暗）
- 正文纸页加微噪点质感（可选，用 `background-image` + 透明度）
- 顶栏底栏保持现有 hover 浮现交互

**优先级**：低，前三个是核心，这个属于锦上添花。

## Assumptions & Decisions

1. **以 webapp 为底座**：不新建项目，直接修改 `webapp/` 目录下的文件，保持其代码风格和文件结构
2. **立绘继续用 PNG**：继续用现有的三张 portrait 图，不替换为像素 SVG
3. **成文视图的头像用立绘**：对话块里的角色头像用 `portrait-*.png` 裁成圆形，与整体风格统一
4. **v0.2 不做数据交互**：所有数据是静态硬编码的演示数据，JS 只做视图切换
5. **信念账本不做展开交互**：默认展示前 3 条，更多用"…"暗示，点击展开留到后续版本
6. **不破坏现有功能**：深浅主题切换、mood 切换、视图切换全部保留并兼容新模块

## Verification Steps

1. **角色卡**：左栏三张角色卡都有情绪条（渐变填充 + 百分比）、信念标签（亲见/推测/被告知颜色区分）、三张卡高度一致不溢出
2. **Tab 切换**：点击"世界黑板"和"成文"能正确切换面板，切换后布局不抖动
3. **成文视图**：章节标题、叙述段落（首行缩进）、对话块（头像+名字+斜体对话）、底部导航都正常显示，对话头像为圆形立绘
4. **时间线**：7 个节点有不同颜色的事件类型点，右上角有图例，当前回合保持红色呼吸动画
5. **主题兼容**：切换深浅主题，新增的情绪条、信念标签、对话块边框颜色都正确响应
6. **响应式**：1024px 和 768px 断点下新元素不溢出，角色卡内容可滚动或自适应
