
# UI 重构方案（信息架构优先）

> 版本 v0.1（提案 · 待确认）
> 定位：解决「**流程编排断裂** + 导航与页面**视觉平淡**」的重构方案。
> 视觉基调沿用 [前端视觉与交互设计规范.md](前端视觉与交互设计规范.md) 的「导播台 + 手稿纸」定位与色板；本文件只解决 **信息架构、流程动线、页面布局、组件与 token 落地**，不改产品逻辑、不改引擎。
> 实测证据（截图）：[docs/mockups/before/](mockups/before/)（1680×1050 视口 + 1680×2200 全页）

## 0. 实测诊断（截图 + 代码双重证据）

### 0.1 路由 × 导航 可达性矩阵

| 路由 | 页面 | 侧栏入口 | 实际可达路径 |
| --- | --- | --- | --- |
| / | HomePage 书架 | 有 · 书架 | 侧栏 |
| /dashboard | DashboardPage 概览 | 有 · 概览 | 侧栏 |
| /maestro | MaestroPage 主笔创作 | 有 · 主笔创作 | 侧栏 |
| /characters | CharactersPage 人物 | 有 · 人物 | 侧栏 |
| /director/:sceneId | DirectorPage 导演台 | 无 | **只能**：主笔页 → 点场景行 → 浮动卡片 → ▶ 进入导演台 |
| /studio/:sceneId | StudioPage 正文协作 | 无 | **只能**：同上；且页内无侧栏 |
| 设定 / 大纲 / 伏笔 / 章节 / 记忆包 / 体检 / 全局设置 | 不存在 | 死链 | 点击无反应 |

死链不是"预留"，是**伪装成可用项的按钮**——视觉与可用项完全相同：

```tsx
// frontend/src/components/backoffice/Sidebar.tsx
{ key: 'foreshadow', icon: '⟡', text: '伏笔' },   // 无 to 字段
...
it.to ? <Link .../> : <a className="nav-item" href="#">...</a>   // 渲染成死链
```

**结论**：10 个导航项里 4 个可用、6 个死链；6 个路由里 2 个无入口。

### 0.2 流程编排断点（本轮主要问题）

五步创作链在 UI 上**不存在**：

```
① 定方向 → ② 生成骨架 → ③ 配角色卡 → ④ 推演回合 → ⑤ 成文精修
   已有        已有          绕路死结       已有          已有
```

**断点 B1 · 没有全局上下文锚。** 四个位置各自实现"当前书"，互不同步：

| 位置 | 实现 | 后果 |
| --- | --- | --- |
| MaestroPage | 本地 state bookId，默认 books[0] | 与其他页不同步 |
| Sidebar | 读 URL ?book= | 主笔页不写 URL → 侧栏高亮丢失 |
| DashboardPage | 读 URL ?book= | 同上 |
| CharactersPage | 自己的 scope select | 从主笔页跳过去，当前书丢失 |

**断点 B2 · 导演台/正文协作是隐式入口。** 入口藏在"选中场景后出现的浮动卡片"里。没点场景 → 按钮根本不存在 → 用户看到的页面"没有入口"。

**断点 B3 · 无"下一步"。** 每个页面都不告诉用户现在该干什么、下一步去哪。

**断点 B4 · 正文协作页脱离导航。** StudioPage 不渲染 Sidebar，只有「← 返回主笔台」，进入后失去全部定位。

**断点 B5 · 角色卡是绕路的死结。** 要成文先要推演 → 推演要先配角色卡 → 角色卡在人物页。现在只靠后端报错文案兜底（P0 的 _ensure_cast），前端没有任何"去配角色"的入口或引导。

## 1. 目标信息架构

### 1.1 主链：五个站点，一条主线

```
                                         ┌───────────────┐
  ① 书架 ──选书──▶ ② 主笔创作 ──选场景──▶ │  ③ 导演台     │ ──推演出成文──▶ ④ 正文协作 ──▶ ⑤ 概览复盘
  (/)              (/maestro)             │  (/director/) │                 (/studio/)    (/dashboard)
       ▲               │                  └───────────────┘                      │              │
       │               │ 配角色卡                                                │ 精修闭环      │ 张力 / 伏笔
       │               ▼                                                         │              │ 一致性诊断
       │          (/characters 人物) ◀──── 未配角色时的高亮引导 ──────────────────┘              │
       └────────────────── 全局上下文条：书 / 章 / 场景 贯穿所有站点 ────────────────────────────┘
```

- **每一步都能"回到上一步 / 进入下一步"**，不再依赖隐藏入口。
- 人物页从"侧栏第 4 项"升级为**流程内的引导站点**：场景无角色卡时，导演台与正文协作给出直达链接。
- 概览复盘既是终点也是仪表盘（张力曲线、伏笔网络、结构诊断、体检）。

### 1.2 侧栏重排：10 项 → 7 项，全部真实可达

分组为「书架」+「创作流程（4 步）」+「资源（2 项）」，每步带**状态点**：

| 新顺序 | 名称 | 路由 | 状态点含义 | 旧归属 |
| --- | --- | --- | --- | --- |
| — | 书架（书列表） | / | — | 保留 |
| 1 | 主笔创作 | /maestro | 有骨架 / 已生成 | 原「主笔创作」+「大纲」+「章节」 |
| 2 | 导演台 | /director/:sceneId | 有推演回合 | **新增入口** |
| 3 | 正文协作 | /studio/:sceneId | 有成文 | **新增入口** |
| 4 | 概览复盘 | /dashboard | 有诊断 | 原「概览」+「伏笔」+「体检」三 tab |
| — | 人物 | /characters | 角色卡数量 | 保留 |
| — | 设定 | /settings | 世界状态 + 书级记忆 | 原「设定」+「记忆包」合并 |
| — | 全局设置（页脚） | /settings?tab=global | — | 原死链 |

**删除的死链与去处**：

| 死链 | 处理 |
| --- | --- |
| 大纲 | 并入「主笔创作」的骨架区（功能已在） |
| 章节 | 并入「主笔创作」的骨架区（功能已在） |
| 伏笔 | 成为「概览复盘」的 tab（数据 foreshadows + build_foreshadow_network 已在） |
| 体检 | 成为「概览复盘」的 tab（/health + 质量数据已在） |
| 记忆包 | 改名并入「设定」（书级记忆本就是设定） |
| 设定 | 变为真实页 /settings：世界状态（S1 world_states）+ 书级记忆 |

> 原则：**导航项要么能到，要么不存在。** 不再保留 href="#"。

### 1.3 全局上下文条 ContextBar（新组件）

所有工作站点顶部固定一条 44px 上下文条，取代现在各页各自的"书切换"：

```
┌──────────────────────────────────────────────────────────────────────────────────────┐
│ 书架 / 异能007 ▾ / 第 1 章 ▾ / 场景 1 ▾        [未配角色 ✕]        ◀ 上一步  下一步 ▶ │
└──────────────────────────────────────────────────────────────────────────────────────┘
```

- 三个下拉分别切书/章/场景，**写进 URL**（?book=&chapter=&scene=，路径参数优先）→ 所有页面共享同一上下文，刷新不丢。
- 中间是**该站点的前置条件状态**：如「未配角色」「未推演」，点击直达修复。
- 右侧「上一步 / 下一步」按主链跳转（末站时"下一步"变"下一场"或禁用）。

实现：新建 frontend/src/context/WorkspaceContext.tsx（Provider 挂在 App.tsx 的 BrowserRouter 下），暴露 { bookId, chapterId, sceneId, setBook, setChapter, setScene, prevStep, nextStep, blockers }。

### 1.4 上一步 / 下一步 语义表

| 站点 | 上一步 | 下一步 | 下一步禁用条件 |
| --- | --- | --- | --- |
| 主笔创作 | 书架 | 导演台（无场景时先聚焦骨架区） | 无场景 |
| 导演台 | 主笔创作 | 正文协作 | 0 回合 |
| 正文协作 | 导演台 | 下一场 / 概览复盘 | 无 |
| 概览复盘 | 正文协作 | — | — |

## 4. 视觉与组件规范补充

### 4.1 新增 token（写入 frontend/src/styles/tokens.css）

| 类别 | token | 值 |
| --- | --- | --- |
| 间距 | --sp-1 … --sp-6 | 4 / 8 / 12 / 16 / 24 / 32 px |
| 圆角 | --r-sm / --r-md / --r-lg / --r-xl | 4 / 8 / 12 / 16 px |
| 阴影 | --sh-1 静置 / --sh-2 悬浮 / --sh-3 浮层 | 0 1px 2px / 0 4px 14px / 0 12px 40px |
| 字阶 | --fs-xs … --fs-2xl | 12 / 13 / 14 / 16 / 20 / 28 px |
| 状态色 | --st-ok / --st-run / --st-warn / --st-err | 共识绿 / 导演金 / 信息蓝 / 张力红 |
| 卡片 | --card-accent-w | 3px（左强调条宽度） |

### 4.2 统一卡片视觉（现在各页卡片风格不一）

- 一律「**左 3px 强调条 + 1px 边框 + --sh-1**」，hover 时 --sh-2 与 translateY(-1px)。
- 强调条颜色 = 语义色（在场/待审/已批准/已驳回/失败）。
- 入场动效统一 0.18s ease-out 淡入上移 4px，不再每页各写一套。

### 4.3 新增共用组件

| 组件 | 用途 | 替换 |

### 4.4 导航页（侧栏）视觉重做

- 分组标题（书架 / 创作流程 / 资源）+ 分组间留白 16px，取代现在 10 项等距堆叠。
- 流程项：左侧**序号徽标**（1–4，圆角 6px），右侧**状态点**（未开始 / 进行中 / 已完成）；当前项用 --accent-gold 左强调条 + 淡金底。

- 页脚「全局设置」保持可见但改为真路由。
- 死链全部移除后，**不存在任何可点击但无反应的项**。
