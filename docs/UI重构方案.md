## 0. 实测诊断（截图 + 代码双重证据）

### 0.1 路由 × 导航 可达性矩阵（改前）

| 路由 | 页面 | 侧栏入口 | 实际可达路径 |
| --- | --- | --- | --- |
| / | HomePage 书架 | 有 · 书架 | 侧栏 |
| /dashboard | DashboardPage 概览 | 有 · 概览 | 侧栏 |
| /maestro | MaestroPage 主笔创作 | 有 · 主笔创作 | 侧栏 |
| /characters | CharactersPage 人物 | 有 · 人物 | 侧栏 |
| /director/:sceneId | DirectorPage 导演台 | **无** | 只能：主笔页 → 点场景行 → 浮动卡片 → ▶ 进入导演台 |
| /studio/:sceneId | StudioPage 正文协作 | **无** | 同上；且页内无侧栏 |
| 设定 / 大纲 / 伏笔 / 章节 / 记忆包 / 体检 / 全局设置 | 不存在 | **死链 href="#"** | 点击无反应 |

结论：**10 个导航项里 4 个可用、6 个死链；6 个路由里 2 个无入口**。死链渲染在 [Sidebar.tsx](file:///e:/novel_desk-agent/frontend/src/components/backoffice/Sidebar.tsx)，视觉与可用项完全相同。

### 0.2 流程编排断点

1. **无全局上下文锚**：4 个位置各自实现"当前书"（Maestro 本地 state / Sidebar 读 ?book= / Dashboard 读 ?book= / Characters 自己 select）→ 跳页丢书。
2. **导演台与正文协作是隐式入口**：藏在"选中场景后的浮动卡片"里，没点场景就不存在 → 这就是"页面没有入口"。
3. **无上一步/下一步**：不告诉用户现在在哪、下一步去哪。
4. **正文协作页脱离导航**：不渲染 Sidebar，只有「← 返回主笔台」。
5. **角色卡是绕路死结**：要成文先推演 → 推演要先配角色卡 → 角色卡在人物页；前端无引导，只靠后端报错兜底。

### 1.3 全局上下文条 ContextBar（新组件，44px）

```
┌──────────────────────────────────────────────────────────────────────────────────────┐
│ 书架 / 雨夜书房 ▾ / 第 1 章 ▾ / 场景 1 ▾     [○ 未配置上场角色 · 一键生成]  ◐主题  ◀上一步 下一步▶ │
└──────────────────────────────────────────────────────────────────────────────────────┘
```

- 三段下拉切书/章/场景，**写进 URL**（`?book=&chapter=&scene=`，路径参数优先）→ 全站共享、刷新不丢。
- 中间是**前置条件状态**（未配角色 / 未推演 / 无正文），点击直达修复动作。
- 右侧主题切换 + 上一步/下一步。

实现：新建 `frontend/src/context/WorkspaceContext.tsx`，Provider 挂在 `App.tsx` 的 `BrowserRouter` 内；暴露 `{ bookId, chapterId, sceneId, setBook, setChapter, setScene, prevStep, nextStep, blockers }`。

## 3. 正文协作页（已确认）

### 3.1 布局与主题

**不做混合**：墨就纯墨、纸就纯纸（曾试过"深色壳 + 宣纸卡片"，已废弃）。

| | 墨模式 | 纸模式 |
| --- | --- | --- |
| 页面/成文底 | `radial-gradient(ellipse at 50% 0%, rgba(74,91,138,.45), transparent 55%)` + `--bg-page` | 同位置换 `rgba(181,69,46,.06)`，底 `#F5EFE0` |
| 面板 | `rgba(21,25,34,.74)`（半透明，渐变透出来） | `rgba(250,246,234,.78)` |
| 正文面板 | `--bg-elevated` + 边框 + 圆角 10（抬升感 = 面板比底亮） | `#FDFAF0` + 边框 |

> 渐变写法**照搬导演台现成实现**（[app.css](file:///e:/novel_desk-agent/frontend/src/styles/app.css) 的 `.workbench` / `.reader`）——"背景不要纯黑"用渐变 + 半透明解决，不加亮色。

### 3.2 正文排版（关键约束）

**参考导演台「成文视图」的排版语言，但排除对话块**——正文协作是小说正文，出现「头像 + 竖条 + 角色名」的剧本化对话块会**突兀**。规则：

- ✅ 用：抬升面板、居中标题 + 朱砂短线、衬线字体、行高 2、首行缩进 2 字、段落间距 0.85em、右上「CH.x · SCENE y / 字数 · 保存时间」、底部字数进度条 + 质检分
- ❌ 不用：`.prose-dialogue`（头像 + mood 竖条 + 角色名 + 斜体台词）—— **该样式只属于剧本台（导演台/剧本产物）**
- 台词以正文形式内嵌，如：`他低声道：“原来如此。”`
- 编辑态才出现"当前段落"极淡高亮 + 左侧细竖条（阅读态不显示）

## 4. Token 与组件

### 4.1 新增 token（`frontend/src/styles/tokens.css`）

| token | 墨 | 纸 |
| --- | --- | --- |
| `--page-grad` | 靛蓝 `.42` 顶部径向 + `--bg-page` | 朱砂 `.06` 同位置 |
| `--stage-grad` | 靛蓝 `.50` + `#0A0D14` | 朱砂 `.07` + `#F0E9D8` |
| `--panel-trans` | `rgba(21,25,34,.74)` | `rgba(250,246,234,.78)` |
| 间距 / 圆角 / 字阶 / 阴影 / 状态色 | 4·8·12·16·24·32 ｜ 4·6·8·10 ｜ 12·13·14·16·20·28 ｜ 3 档 ｜ ok/run/warn/err ｜ 沿用现有 | 同 |

### 4.2 统一卡片

左 3px 语义强调条 + 1px 边框 + `--shadow-sm`；hover → `--shadow-md` + `translateY(-1px)`；入场统一 0.18s ease-out 淡入上移 4px。

### 4.3 新增共用组件

| 组件 | 用途 |
| --- | --- |
| `ContextBar` | 全局书/章/场景 + 前置条件 + 上一步/下一步 |
| `EmptyState` | 图标 + 标题 + 说明 + 主/次按钮（取代各页 12px 灰字） |
| `StepFlow`（侧栏内） | 4 步序号 + 状态点 |
| `Tabs` | 概览复盘（张力/伏笔/体检）、共创（对话/记忆）、设定（5 tab） |
| `ScoreRing` | A2 评分环 + 5 维条 |

### 4.4 明确不做的技术选择

- **不引入 Tailwind**：现有问题不是"写 CSS 的姿势"，而是 IA 与内容区排版语言；全量迁移会产生巨大无收益 diff。等价收益（一致性）用 token + 原子组件拿到。**新模块从零写时局部试点**（第一个候选 = 素材库）。
- **不把"纸卡片"塞进深色壳**（混合方案已废弃）。
- **不在正文协作用剧本化对话块**。
- **不动引擎**：`services/engine/*`、质量阈值、提示词、数据表结构一律不碰。
