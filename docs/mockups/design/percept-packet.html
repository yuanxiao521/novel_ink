「感知包」是什么：从"拼好的字符串"变成"可检查的中间产物"

行为等价，只是中间多一层结构；先只落 主笔 与 责编 两个样板

现状 · 字符串（角色 agent 的 perceive_context 输出）

你（陈默）：书房主人，敏锐冷静的收藏家
【性格】敏锐、克制、重证据
【底线】不施暴；不承认不实指控
【目标】查明真相(权重0.70)；守住对李文的承诺(权重0.40)
【你已知】「保险柜被动过」(亲见)；「李文深夜出门」(推测)
【眼前】窗外下着雨；书房保险柜门半开
【近况】李文：这文件……你什么时候放的？
四个问题：① 不可断言——"它到底看到了什么"写不出测试；② 裁剪不留痕——哪条事实被可见度裁掉了、为什么，看不到；③ 加来源只能往里塞，顺序即隐式优先级；④ 没有 token 预算，塞多了只能靠人肉调。

目标 · 结构化感知包 PerceptPacket

{
  "who": { "id": "chenmo", "name": "陈默" },
  "scope": "character_view",          // 角色视角 / 场景 / 书级 / 任务
  "sources": ["card","beliefs","facts","events"],
  "budget": { "max_tokens": 900, "used": 412 },
  "blocks": [
    { "kind": "self",    "text": "书房主人…" },
    { "kind": "goals",   "items": [{"text":"查明真相","weight":0.7,"reason":""}] },
    { "kind": "beliefs", "visibility": "own",
      "items": [{"text":"保险柜被动过","channel":"亲见","src_event":"E-003"}] },
    { "kind": "facts",   "visibility": "filtered",
      "items":   [{"id":"F-1","text":"保险柜门半开"}],
      "dropped": [{"id":"F-2","reason":"visible_to 不含本角色"}] },
    { "kind": "events",  "window": "last6", "items": [ … ] }
  ]
}
换回四件事：① 可断言——能写测试"写手的感知包里不含 F-2"；② 裁剪留痕（dropped 带原因）→ 直接落实"静默降级必须反馈"的项目纪律；③ 一处产出、多处渲染——同一包喂不同 agent，只换模板；④ 可存档可复现——事后能回答"当时它到底看到了什么"。
做法：perceive(scope, ctx) → PerceptPacket，再由各 agent 的模板渲染成 prompt（现有四层顺序不变）→ 行为等价。
