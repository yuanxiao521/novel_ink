6 个边界问题（本次要拍板）

P1 编排者缺位：流程写死在 service.py，工具散落 7 个路由 → agent 无法复用按钮能力
P2 主笔只到"结构"为止：正文页没有 agent，作者的"说不清但看得出不对"无处表达
P3 文字层无责任人：写手/体检/润色/质检各干一段、互不通信；A2 的"评审"有职责却没身份没入口
P4 角色不在场：角色 agent 只在导演台跑；写手写正文时只有"角色卡文本"，没有角色的当场反应
P5 命名混淆：页面叫"导演台"但操作者是作者；"导演 Agent"其实只是回合提示生成器
P6 彩排决策无人负责：现在只能人工判断"这场要不要先演"，没有任何 agent 给建议

可以被信任、不要重做的部分

校验层（0-token）：S2/A3 规则、护栏、R1–R7 诊断 —— 已实测有效，只该被工具化，不该被重写
账簿层：伏笔/信念/世界状态三本账已闭环，只缺"谁来读、怎么用"
LLM 客户端约束：只有 call_strong(json_schema)，无 function calling → 编排第一版走"计划式工具调用"
