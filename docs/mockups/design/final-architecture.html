纪律：Redis 只做 传输 / 缓存 / 锁，绝不放业务事实（三本账、正文、任务单真值永远在 PG）
条件①多进程：uvicorn --workers>1 或独立 worker → 黑板与 SSE 需跨进程广播
条件②后台长任务：批量写手 / 批量彩排 → 需要队列与断点续跑
条件③多人实时：多人同看一台戏 → pub/sub 广播
条件④高频进度：进度/心跳写 PG 太重 → 缓存
当前判定：A/A+ 批任务单量小、要审计、要跨会话 → 直接落 PG，不引 Redis
