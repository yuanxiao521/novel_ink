② 导演台到底放哪？三个选项

A 可选彩排（建议）：默认跳过；场景级开关「先演一次」。主链 = ①→③→④
B 主链必经：每场先演后写——产出更"活"，但成本 ×N、作者等待长
C 混合：重头戏（高潮/对决/收束）自动标"建议排演"，其余跳过
回流（现在的缺口）
· ④ 发现第 3 章太平 → 现在只能手动回 ① 改
· ③ 写手说"本场目标没定" → 应能就地改场景字段，不必跳页
· ② 演出的高光若写手没用上 → 没有任何提示（缺"素材使用率"）
