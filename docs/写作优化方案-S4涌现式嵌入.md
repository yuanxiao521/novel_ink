# 优化方案 S4 · 涌现式嵌入（分层 + 桥接）

> 版本 v0.1 · 2026-09-13 · 定位：**亮点项**（不是痛点修正）
> 上位文档：`docs/写作痛点清单与优先级.md`（S4）
> 决策已确认（2026-09-13）：**think 必须落档，且"思考"与"内心独白"分层**（前端小箭头展开）；高光提炼先确定性后 LLM；素材复用灵感池；触发=手动+S3 建议；导出 Markdown+JSON；桥接=勾选才注入；一章只下钻 1-2 个重头场景。

## 1. 现状盘点（真实代码对照）

## 2. 目标（三阶段）

1. **产物定型**：涌现直接产出**剧本/对话记录**（回合事件流 + 各角色思考），可导出，**不再强行转成叙述正文**；
2. **高光提炼**：把涌现里的高光（冲突回合 / 高潮台词 / 转折）提炼成**素材**，进灵感池；
3. **桥接**：作者勾选素材 → **并增注入写手 prompt**（两类：高光素材 + 角色思考/动机依据），写手扩写时"看见"涌现成果。

## 3. 设计

### 3.1 思考层落档（用户已确认 · 并增）

```
TurnArchive 并增：
  thoughts: list[dict] = []      # [{char, monologue, emotion, reasoning, raw}]
                                 #   monologue = 内心独白（第一人称心里话，剧本/心理素材）
                                 #   reasoning = 推理/动机依据（落正文时给写手的"为什么"）
                                 #   raw = LLM 原始结构化产物（卡里 think_schema 可覆盖字段，故整体留档）
```

- **归集时机**：`_archive_turn` 读 `sim.scratch["thoughts"]` → 写入本回合归档 → **清空 scratch["thoughts"]**（避免跨回合覆盖，D2 修复）；
- **兼容**：旧归档无该字段 → 默认空列表（`并增`，不破坏回放）；
- **不写 `events`**：思考不进事件流（否则会污染"角色行动"与账本），只在归档里留档。

### 3.2 剧本产物形态

| 形态 | 内容 | 用途 |
| -- | -- | -- |
| **Markdown 剧本体** | `【场景】…` / `角色：台词` / `（动作）` / `〔思考·角色〕…`（可选开关） | 人读、导出、投稿剧本 |
| **JSON 结构化** | 回合 + 事件 + 张力 + 思考（同一份数据的机器形态） | 桥接/二次加工 |

- 张力/趋势作为**可选标注**（`〔张力 62↑〕`），默认关闭，导出时勾选；
- 导出粒度：**单场景** / 全书（`GET /books/{id}/script`、`GET /scenes/{id}/script`）。

### 3.3 高光提炼（先确定性，预留 LLM 口子）

```
确定性高光 = cls=="type-conflict" 的回合
           ∪ 张力 >= 场景峰值×0.8 的回合
           ∪ 台词长度 Top-2 的回合（长台词=信息密集）
           ∪ 收尾回合（收束/举手前最后一回合）
```
- 每条高光给：`{scene_id, turn, kind, tension, quote, chars}`；
- LLM 提炼**本期不做**，留接口（`engine/emergence.py::extract_hits(llm=None)`，future 传 llm 即启用）。

### 3.4 素材落点：复用灵感池（零新表）

- 采纳高光 → 写一条 `inspiration_cards`：`type=plot|character|world`、`source="emergence"`、`desc`=情境摘要、`adopted=false`；
- 复用现有：`POST/PUT/DELETE /inspirations`、`adopted` 标记、Maestro 灵感面板、`plan inspiration_ids`；
- **零迁移、零新表、UI 现成**。

### 3.5 桥接：勾选才注入（作者掌控）

- 写手 prompt **并增两段**（仅在作者勾选时出现）：
  1. `【涌现素材】` 已采纳灵感卡（title/desc）；
  2. `【角色动机依据】` 该场景角色的 `thoughts.reasoning`（落正文时的"为什么"——正是用户指出的"落正文也需要思考层面"）；
- 不自动注入未勾选项（避免 prompt 膨胀 + 守住 A4"作者掌控"红线）。

### 3.6 触发：手动为主 + S3 建议

- 前端「剧本视图」提供"下钻涌现"入口（重头场景手动跑）；
- S3 诊断（`R3 高潮缺失`/`peak_chapter`）在概览页给"建议下钻"提示，**不自动执行**。

### 3.7 前端：导演台「剧本视图」

- 回合列表（复用现有回合数据）→ 每回合：`cls` 标签 + 摘要 + 角色行动/台词；
- 每回合/每角色 **`▸ 思考` 小箭头展开**（独白 / 推理 分栏显示）；
- 两个按钮：**「导出剧本」**、**「采纳为素材」**（勾选高光回合）；
- 明确不做：在导演台直接写正文（那是 StudioPage 的事）。

## 5. 验收标准（可测）

1. **思考落档**：跑一回合后，`TurnArchive.thoughts` 含各角色条目（`monologue`/`reasoning` 分开）；**重复回合不互相覆盖**；旧归档（无该字段）仍可回放；
2. **思考不入事件流**：`events` 里不出现思考条目（不污染行动/账本）；
3. **剧本导出**：Markdown 含 `场景/角色：台词/（动作）`，勾选后含 `〔思考·角色〕` 与张力标注；JSON 结构完整；
4. **高光提炼**：冲突回合 / 峰值张力回合 / 收尾回合被标为高光，且**可复现**（纯函数单测）；平淡回合不误报；
5. **采纳为素材**：高光 → 灵感卡（`source="emergence"`、`adopted=false`），前端灵感面板可见；
6. **桥接勾选注入**：勾选后写手 prompt 出现 `【涌现素材】`/`【角色动机依据】`；未勾选则**不出现**；
7. **回归**：全量 pytest 全绿；S1/S2/S3/A3 行为不回退。

## 6. 明确不做 / 触发条件

| 不做 | 原因 | 触发何时纳入 |
| -- | -- | -- |
| 把涌现**自动转成正文** | 这正是原先的矛盾（涌现是强互动/剧本味，网文需强叙述） | 不纳入（分层是本方案的立身之本） |
| LLM 提炼高光 | 先确定性跑通；LLM 提炼要钱且不稳定 | 确定性高光被作者实际用起来后 |
| 自动注入未勾选素材 | prompt 膨胀 + 违背 A4 作者掌控 | 不纳入 |
| 新表 `emergence_hits` | 灵感池已具备全部能力（采纳流 + UI） | 需要"高光版本演进/多轮对比"时 |
| 导演台内写正文 | 职责边界：正文在 StudioPage | 不纳入 |
